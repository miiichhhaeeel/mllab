# ML Programs

This folder contains five Python machine learning programs:

1. `linear_ridge_lasso.py` — Linear, Ridge, and Lasso Regression
2. `logistic_regression.py` — Logistic Regression with and without feature scaling
3. `naive_bayes.py` — Multinomial and Bernoulli Naive Bayes
4. `knn_fashion_mnist.py` — K-Nearest Neighbors using Fashion MNIST
5. `linear_svm.py` — Linear Support Vector Machine using the Iris dataset

## Requirements

Install the required libraries with:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Some programs download datasets from the internet when they run.
